# Woodpecker

## Назначение

Иногда возникает задача сделать вызов какого то кода, который может заврешиться ошибкой. Например - REST вызов, отправка сообщения какой-то брокер сообщений. Как правило, это вызовы внешней системы, с использованием сетевого взаимодействия. 

Такие вызовы могут завершиться ошибкой, вызваной недоступностью сети, или самого внешнего сервиса. 

В таких случаях одна из стратегий - повторить вызов спустя какое-то время, может быть нескольк раз. 

Эта библиотека реализует паттерн надежной отправки. Идея реализовать что-то вроде transaction outbox - когда мы сохраняем запрос в локальное хранилище, и только потом начинаем делать вызовы, чтобы в случае недоступности внешней системы повторить заново.
